# GitHub Project 運用メモ

## 前提

- Project は `1個`
- Issue は `Common / iOS / Android` の3系統で管理する
- タイトル先頭に `Platform` と `Phase` を入れる
  - 例: `[Common][P0]`, `[iOS][P1]`, `[Android][P2]`

## 列

- `Todo`
- `Ready`
- `In Progress`
- `Blocked`
- `Done`

## ラベル

- `common`: 共通タスク
- `ios`: iOS固有タスク
- `android`: Android固有タスク
- `ui`: 画面実装
- `auth`: ログイン、認証
- `portal-access`: セッション管理、取得基盤
- `parser`: HTML解析
- `board`: 掲示板
- `timetable`: 時間割
- `integration`: 結合
- `qa`: 動作確認

## 担当

- `scottleoishii-dev`: ハシグチ
- `kohei-commit`: タナカ
- 未割当て: Android担当未確定分、または全体作業

## Phase の意味

- `P0`: 前提整理、調査、設計
- `P1`: UI実装、取得処理実装
- `P2`: 結合、保存方針整理
- `P3`: 最終確認、バグ修正

## 見方

- `Platform` はタイトル先頭で見る
- `Phase` もタイトル先頭で見る
- `Labels` は機能カテゴリを見るために使う
- `Blocked` に移したら issue コメントで止まり理由を書く
